# 永久成长 / 知识城设计 — 知识神塔

> 状态：v1（已对齐核心结构、双货币用途、6 建筑布局；卡组模板/家长看板等晚做内容仅留接口）
> 上下文：本 spec 与战斗 spec、Run spec 并列。定义"局外"的全部内容——玩家进游戏首先看到的主界面、永久解锁、图鉴、备战入口。

---

## 设计目标

- **持续动力**：每次撤退/通关后玩家**有事可做**（解锁、图鉴、看进度）。
- **学习闭环**：知识城不是单纯升级商店，是**学习反馈中心**——图鉴 + 训练场承担复习功能。
- **教育友好的 UI**：静态俯视角小镇 + 建筑入口（不做完整 RPG Maker 移动），保留 RPG 感但成本低。
- **MVP 单职业**：先验证整套循环，多职业作为通关后第一个解锁。
- **学科无关**：知识城布局/系统全引擎层；学科切换 = 内容包注册自己的"主题图鉴 / 题库"。

## 6 大建筑职责

### 🏛 神塔之门（Tower Gate）

**作用**：进入 Run 的入口。

**子界面**：
1. 楼层选择：神塔截面图，已通关层亮金 + 三星记录，未解锁层灰显
2. 选定楼层 → 楼层简介页（单元名 / 推荐时长 / 子主题 / Boss 名）
3. → 备战界面（编辑卡组 + 选职业 + 装备卷轴 + 复习卡片）
4. → [启程!] → 切换到 RunMap 场景

**交互细节**：
- 已锁层显示解锁条件："通关 1F 即可解锁"
- 通关 1F 后右侧亮起 "1F+ 难度升阶"（碎片解锁后启用）

### ⚔ 训练场（Training Ground）

**作用**：纯学习模式，无 HP 压力，从 SRS 取最弱 10 题让玩家专项突破。

**核心机制**：
- 进入 → 调用 `SrsSystem.get_weakest_questions(10)`
- 每题以"卡片对话战"同款 UI 呈现，但**没有敌人 HP / 玩家 HP**
- 答完 10 题 → 结算：全对 +50 词晶、答对率 ≥80% +30、≥50% +10、<50% 0
- **从来不显示"失败"**

**意义**：
- Run 失败时玩家会想"我哪里不会"，训练场给出确切答案
- 周末或考试前的纯学习入口
- 家长会重视"有没有专门复习模式"

**实现复用**：UI 同战斗里的卡片对话战，去掉敌人立绘和血条；逻辑层只跑 ChallengeValidator。

### 📚 图鉴馆（Codex Hall）

**作用**：收集陈列 + 学习参考。

**5 种图鉴**（标签页切换）：

| 图鉴 | 解锁条件 | 内容 | 学习用 |
|------|---------|------|------|
| 📕 卡片图鉴 | 获得过该卡 | 单词/短语/句型 + 例句 + 发音按钮 | 点单词复习发音和释义 |
| 👹 敌人图鉴 | 击败过 | 立绘 + 弱点 + 攻击模式 + 剧情 | 提前知道下次怎么打 |
| 👑 Boss 图鉴 | 通关过 | 多阶段台词 + 战斗记录 + 最快通关时间 | 重读剧情 |
| ⚔ 装备图鉴 | 拾得过 | 装备外观 + 词条 + 出处 | — |
| 📜 剧情图鉴 | 触发过事件 | 剧情碎片汇总（按楼层）| 重读故事 |

**每个图鉴页头**：
- 进度条 "15/40 已解锁"
- 100% 完成 → 解锁称号 / 装饰 / 5 蓝图碎片

**MVP 范围**：仅做 卡片 + 敌人 两种图鉴，其余预留入口。

### 🔮 水晶集市（Crystal Market）

**作用**：用词晶买**永久小升级**。

| 品类 | 内容 | 价格 |
|------|------|------|
| **永久属性** | 起手 HP +5（5 档：100/105/110/115/120）| 50/100/200/400/800 |
| | 起手词晶 +20（3 档）| 100/200/400 |
| | 起手抽牌 +1（仅 1 档）| 500 |
| **永久卡解锁** | 解锁特定 common/rare 单卡入永久卡池 | 30-100 |
| **训练场入场券** | 1 次额外训练场（SRS 不重复同题）| 20 |
| **复习道具** | 一次性 Spice 道具（带入下局战斗）| 50-100 |

**UI**：列表式，每行一个商品，左侧图标 + 名字 + 描述，右侧价格 + [购买] 按钮。已购买的标灰。

### 🧩 蓝图工坊（Blueprint Workshop）

**作用**：用蓝图碎片买**永久重大解锁**。

| 品类 | 内容 | 价格 |
|------|------|------|
| **职业** | 解锁新职业（学者 / 战士 / 治愈师）| 10 碎片 |
| **新楼层** | 解锁下一楼层（也可由 Boss 通关解锁）| 5 碎片（加速）|
| **难度升阶** | 1F+ 模式（题更难、奖励 +30%）| 15 碎片 |
| **传说卡入池** | epic / legendary 卡入永久池 | 5-10 碎片 |
| **新 Spice 卷轴类型** | 永久 Spice 类型解锁 | 3 碎片 |
| **卡组槽位** | 起手卡组上限 8 → 10 → 12 | 10/15 碎片 |

**UI**：树状解锁图（节点连线），看得到"下一步往哪走"。

### 🛏 守护者驻地（Guardian's Quarters）

**作用**：查看角色信息 + 永久卡组 + 装备列表。

**子标签**：
1. **角色页**：当前职业 / 等级（基于已永久升级数）/ 永久属性总览
2. **卡组库**：所有已解锁卡片的浏览（区别于图鉴的是**这是可选用清单**）
3. **装备背包**：所有已获得的装备 + 当前出战装备
4. **卷轴库**：所有 Spice 卷轴 + 当前出战卷轴
5. **三星挑战进度**：每楼层 3 颗星的当前状态

**MVP 范围**：角色页 + 卡组库 + 三星进度页；装备 / 卷轴在 Phase 2 之前可空白占位。

## 双货币流转

```
[战斗节点] → 词晶 +5~15 / 局
[精英节点] → 词晶 +20~30 / 蓝图 0-1（10% 概率）
[Boss 节点] → 词晶 +50 / 蓝图 +1 (小 Boss) +3 (Final)
[商人节点] → 消费词晶（局内）
[神秘事件] → 偶发词晶 / 蓝图

▼ 局结算

通关 → 词晶 100% 入仓库 / 蓝图 100% 入仓库
撤退 → 词晶 70% 入仓库  / 蓝图 100% 入仓库

▼ 知识城

水晶集市 ← 词晶
蓝图工坊 ← 蓝图碎片
```

**经济节奏目标**：
- 通关 1F 一次：~200 词晶 + 5 碎片
- 一档永久 HP 升级：~50-200 词晶（1-2 局可拿）
- 解锁第二职业：10 碎片（约 2 次通关）
- **永远有目标可买，但不会一晚解锁完**

## 卡片状态分级

```
所有卡片
   ├─ 未发现：图鉴中显示问号
   ├─ 已发现：曾经在战利品池中见过 → 进入图鉴
   ├─ 已解锁：永久入池（备战时可选入起手卡组）
   └─ 已装备：本局起手卡组中
```

**解锁路径**：

| 来源 | 量级 |
|------|------|
| 起始 | 12 张基础卡 |
| 战斗 3 选 1（局内）| ~3-5 张/局，但**仅本局有效**，回基地不带走 |
| 通关楼层奖励 | 通关 1F → 解锁 5 张专属卡入永久 |
| 水晶集市买 | 30-100 词晶/张 |
| 蓝图工坊买（传说卡）| 5-10 碎片/张 |

→ 这意味着：**局内的卡只是"试用"，永久卡靠通关 + 商店购买**。这避免"局内拿到强卡，下局就习惯了"。

## 三星挑战系统（接口）

每楼层 3 颗星：
- ⭐ 通关
- ⭐⭐ 一次性不撤退通关
- ⭐⭐⭐ 用至少 N 张新卡通关（N = 楼层卡池 30%）

**存储位置**：`save.three_star_progress = { "1F": [bool, bool, bool], ... }`

**MVP 实现**：
- 仅记录星级
- 守护者驻地的"三星挑战进度"页可看
- 全 3 星 → 解锁 1 蓝图碎片 + 称号
- 全楼层全 3 星 → 解锁特殊装饰
