# Run 结构设计 — 知识神塔

> 状态：v1（已对齐核心结构与资源经济；卡片奖励池/职业起手/楼层难度升阶等细节将由后续 spec 决定）
> 上下文：本 spec 与战斗 spec（`2026-05-04-battle-system-redesign.md`）并列，定义"一局游戏"的整体节奏、节点构成、资源流转、死亡/胜利机制。

---

## 设计目标

- **教育节奏对齐**：1 个 Run = 1 个单元（楼层），覆盖该单元的所有子主题（词汇 + 语法等混合内容）。
- **三幕式紧绷感**：每 Run 3 个 Boss（杀戮尖塔三幕），递进考核单元子主题，最终 Boss 综合考。
- **教育友好的失败处理**：死亡 = 撤退（不是 Game Over），保留绝大部分收益，鼓励持续游玩。
- **配置驱动 Run 长度**：内容包决定一局多长（小学 15-20min，初中 30-40min），引擎不写死。
- **双资源经济**：日常资源（词晶）+ 稀有资源（蓝图碎片）分别支撑短/长线。

非目标：
- 不做无尽塔/竞速排行（教育游戏不该挤压学习深度）。
- MVP 不做"局内时间限制"（不让玩家因为慢就输）。

---

## 总览：一局 Run 的形态

```
玩家在【知识城】选楼层（= 单元）→ 备战 → 进入 Run

[出发点 · 守护者驻地]
   ├─ 满血 + 起手牌组 + 已装备的卷轴/装备
   └─ 显示完整 Act 1 地图
        │
        ▼
   ACT 1   (n 个节点，每排 1-3 个)
        ├─ 战斗 / 精英 / 商人 / 休息 / 谜题 / 神秘
        │   └─（玩家走一条路径到 Boss A）
        ▼
   [Boss A 小 Boss · 子主题 A]
        ▼
   【中场营地 · Camp】
        ├─ 3 选 1 卡片奖励
        ├─ 选择 1：升级一张已有的牌
        ├─ 选择 2：少量回血（最大 HP 30%）
        ├─ 选择 3：再看一遍本 Act 的复习卡（学习强化）
        └─（玩家选 1 项）
        ▼
   ACT 2   (m 个节点，难度上一档)
        ▼
   [Boss B · 子主题 B]
        ▼
   【中场营地】
        ▼
   ACT 3   (k 个节点，难度再上一档)
        ▼
   [最终 Boss · 单元综合]
        ▼
   [Run 结算]
```

## 节点类型

| 类型 | 图标 | 时长 | 内容 | 主要奖励 |
|------|-----|------|------|---------|
| **战斗** | 🗡 | 1.5-2 min | 1 个普通敌人，标准卡片对话战 | 词晶 + 3 选 1 卡片 |
| **精英战斗** | 💀 | 2.5-3 min | 1 个精英敌人，HP/伤害更高，特殊机制 | 词晶 + 3 选 1 卡片 + 装备 / 蓝图碎片（小概率） |
| **商人** | 💰 | 0.5 min | 用词晶买卡 / 买装备 / 移除一张牌 / 升级一张牌 | — |
| **休息** | 🔥 | 0.3 min | 选 1：回 30% HP / 升级一张牌 / 看复习卡 | — |
| **谜题** | 📜 | 1-1.5 min | 单题挑战（高难度题），答对掉装备/卷轴 | 装备 / 卷轴 |
| **神秘事件** | ❓ | 0.5-1.5 min | 文字事件，多分支选择，结果随机（好/坏/中性）| 随机 |
| **小 Boss** | 👑 | 2.5-3 min | Act 末尾，子主题考核 | 词晶 + 蓝图碎片 + 装备 |
| **最终 Boss** | 🏆 | 3-4 min | Run 末尾，单元综合考核（多阶段）| 大量词晶 + 蓝图碎片 + 传说装备 |

## 路径地图（Slay-Spire 分叉树）

### 生成规则

- Act 进入时显示完整地图（3-4 排节点 + 连线）
- 玩家从底部出发，每排选 1 个节点，沿连线前进
- **节点位置预生成**（玩家可看后续路径，提前规划买什么、走精英还是绕路）
- 每排节点数 1-3 个；连线规则：当前节点可连到上一排的左/中/右 1-2 个节点

### 节点分布约束（避免不可玩布局）

- 商人节点：每 Act 至少 1 个
- 休息节点：进入 Boss 前的 1-2 排里至少有一个可达路径
- 精英节点：不能在 Act 第 1 排（玩家刚来还没卡组）
- Boss 前置节点：必须是某种可选的"调整型"（休息 / 商人 / 谜题），让玩家进 Boss 前能微调

## 资源经济：双货币

### 🔮 词晶（Knowledge Crystals）

- **来源**：每个战斗节点 +5~15 / 精英 +20~30 / Boss +50 / 神秘事件偶发
- **用途**：
  - **局内**：商人买卡（10 词晶）、买装备（20 词晶）、移除一张牌（30 词晶）、升级一张牌（25 词晶）
  - **局外**：知识城里**小型永久升级**（起手 HP +5、起手抽 +1、新卡片入池）
- **结算**：通关携带 100%，撤退携带 **70%**（30% 损耗，作为风险提示）
- **典型一局产出**：通关一局 ~150-200 词晶，撤退 ~70-100 词晶

### 🧩 蓝图碎片（Blueprint Fragments）

- **来源**：仅 Boss 必掉（小 Boss 1 / 最终 Boss 3）+ 精英战 10% 概率掉 1
- **用途**：仅用于**重大永久解锁**
  - 解锁新职业（10 碎片）
  - 解锁新起手卡片入池（5 碎片）
  - 解锁楼层难度升阶（15 碎片）
  - 解锁新 Spice 卷轴（3 碎片）
- **结算**：通关 100%，撤退 **100%**（稀有资源永远保留，避免玩家恐惧 Boss）
- **典型一局产出**：通关一局 ~5 碎片，撤退 ~1-3 碎片

### 资源平衡示例

|  | 通关 | 撤退（在 Boss B 死） |
|---|---|---|
| 词晶（200 累计）| 200 | 140（×0.7）|
| 蓝图碎片（5 累计）| 5 | 5 |
| 卡片 / 装备 | 全弃，回基础牌组 | 同 |
| 图鉴 / 解锁状态 | 累积 | 累积 |

## 死亡/胜利流程

### 撤退（HP 归零）

```
战斗失败 → 全屏淡入"撤退"画面
   ┌──────────────────────────────┐
   │   你被前辈守护者带回知识城...    │
   │                                │
   │   🔮 词晶  保留 70%    +98     │
   │   🧩 蓝图碎片  保留全部  +3     │
   │   📖 图鉴解锁  4 项新内容        │
   │                                │
   │   "每次撤退都是新的成长"          │
   │   [回到知识城]                  │
   └──────────────────────────────┘
```

- 整个 Run 牌组 / 装备 / 临时遗物 全部丢弃
- 货币按比例结算入永久仓库
- 图鉴 / 已遭遇敌人 / 已获取卡片元数据 全部累积
- **不显示"失败"字样**，全程"撤退" / "知识不足" / "下次更好"

### 通关（3 Boss 全胜）

```
最终 Boss 倒下 → 全屏胜利画面 + 慢动作 + BGM 高潮
   ┌──────────────────────────────┐
   │   ★ 单元 1F 形容词初阶 通关 ★    │
   │                                │
   │   🔮 词晶 +200                  │
   │   🧩 蓝图碎片 +5                │
   │   🏆 传说装备「沉默之书」        │
   │   📖 图鉴 +12                   │
   │   ⭐ 三星挑战 1/3 完成           │
   │                                │
   │   [回知识城] [再战 1F]           │
   └──────────────────────────────┘
```

通关额外：
- 解锁下一楼层（如果是该单元首次通关）
- 三星挑战进度（不掉血通关 / 不撤回 1 张牌通关 / 不用 Spice 通关）

## 中场营地（Camp）

每个 Boss 战胜后进入。

```
你在守护者驻地小憩了片刻。

[3 选 1 卡片奖励]：
   ┌────────┬────────┬────────┐
   │ [brave] │[strong]│ [跳过] │
   │ 形容词8 │ 形容词6 │  +5晶 │
   └────────┴────────┴────────┘

[选 1 个营地行动]：
   🗡 升级一张已有的卡（伤害 +2 或新增效果）
   ❤ 回复 30% 最大 HP
   📚 复习卡片轮播（再看一遍 Act X 的单词，看完 +5 词晶）

[启程下一 Act!]
```

设计意图：
- **3 选 1 卡片**：维持牌组成长节奏（每 Act ~1 张新卡）
- **营地行动**：3 个截然不同的选项，**强迫策略权衡**
  - 缺血选回血
  - 卡组弱选升级
  - 想多学选复习（兼顾教育目的）

## Boss 设计原则（细节由 Boss spec 定）

### 小 Boss（Boss A / Boss B）
- 单阶段
- HP 中等（玩家应能 5-8 回合击败）
- 必掉 1 蓝图碎片 + 装备 / 卷轴 / 卡片
- Challenge 仅来自该 Act 的子主题

### 最终 Boss（Boss C）
- **多阶段**（≥2 阶段，参考现有 LibrarianBoss 模板）
- HP 高，需 8-15 回合
- Challenge 混合该单元**所有子主题**（A + B + C）
- 必掉 3 蓝图碎片 + 传说装备
- 阶段切换时台词推进剧情


## MVP 范围

### 必做
- `RunState` autoload（与 GameState 协同）
- 三幕路径地图生成 + UI
- 5 种节点类型（战斗 / 精英 / 商人 / 休息 / Boss）—— 谜题/神秘/事件先不做
- 1 个完整楼层数据（1F 形容词初阶 + 3 Boss）
- 双资源（词晶 + 蓝图碎片）
- 撤退 / 通关结算
- 中场营地（3 选 1 卡 + 1 个营地行动）
- 备战界面（编辑卡组 + 复习卡片）

### 不做（推迟）
- 谜题 / 神秘事件 节点
- 三星挑战
- 多职业（MVP 单职业）
- 楼层难度升阶（解锁 1F+ 模式）
- 进阶 Spice 卷轴

## 测试策略

### 单元测试（GUT）
- `RunMapGenerator` 生成的地图：节点数对、分布约束、所有节点可达
- `RunState` 状态机：Act 切换、HP/词晶/碎片增减、撤退/通关结算
- 资源结算公式（70% 撤退 / 100% 通关）

### 集成测试
- 完整一局：起点 → Act 1 → Boss A → Camp → Act 2 → Boss B → Camp → Act 3 → 最终 Boss → 结算
- 撤退路径：在 Act 2 死 → 资源结算正确

### 手动测试
- 18 分钟感觉（实测一局是不是真的接近 18 分钟）
- 路径选择体验（玩家能不能看清地图、做出有意义的决策）
- 撤退情绪（"我又死了"还是"下次更好"）

## 验收标准

- [ ] 玩家可在知识城选楼层进入备战界面
- [ ] 备战可编辑起手卡组、复习卡片、点启程
- [ ] 启程后看到 Act 1 完整地图，可选路径前进
- [ ] 战斗节点 / 精英 / 商人 / 休息 4 种节点都能进入并完成
- [ ] 击败 Act 1 Boss → 中场营地 → 卡片 3 选 1 + 营地行动 → 进入 Act 2
- [ ] 击败 Final Boss → 通关结算 → 词晶/碎片 100% 入仓库
- [ ] 任意点 HP 归零 → 撤退结算 → 词晶 70% / 碎片 100% 入仓库
- [ ] 单测覆盖资源结算与地图生成 ≥80%
- [ ] 一局通关时长 在 15-22 分钟之间（小学 1F）
