## 世界观核心

**知识神塔** —— 连接天地的圆柱建筑，每层是一门学问。

> 很久以前，神塔屹立金光之中，词灵自由飞舞。
> 直到一天，遗忘之主降临，知识被扭曲，文字成了怪物，塔身崩塌。
> 但塔不会真正消失——它在等待新一代守护者，重新登塔，唤醒沉睡的知识。

**关键设定**：
- Boss **不是反派**，是**被混沌侵蚀的知识看守**。打败 = 救援。
- 玩家答对题 = 用真知识反制混沌。
- 塔有 11 层（0F 入门村 + 1F-10F 主路线）。
- 终极反派**遗忘之主曾是上一代守护者**（Phase 2-3 揭示）。

## 角色清单

### 玩家：守护者
- 12 岁少年/少女（性别玩家选）
- 沉默主角，不直接说话
- 立绘：1 张正面（用于剧情）+ 1 张战斗背影（用于战斗界面）

### 词语之师（导师）
- 老者，戴金边眼镜，手持羽毛笔
- 温柔严厉，喜欢举例
- 几乎每个楼层简介都出场
- 立绘：3 表情（normal / happy / serious）

### 长老
- 知识城广场 NPC
- 撤退时安慰，通关时祝贺
- 暗示主线伏笔
- 立绘：2 表情（normal / smile）

### 0F Bosses

#### 字母混乱者（0F-A）
- 设定：本是字母老师，被混沌侵蚀只会念错字母
- 战前："A...B...C...D...等等不对...这个是什么..."
- 战后："谢谢你...我记起来了，我教过孩子们 ABC..."
- 立绘：2 表情（侵蚀 / 觉醒）

#### 发音之灵（0F-B）
- 设定：本是发音教师，现在只能模糊发音
- 战前："听...听...啊...我说不清楚..."
- 战后："你能听懂我！谢谢..."
- 立绘：2 表情

#### 字母守关者（0F-Final）
- 设定：守护塔底字母厅的灵体
- 战前（双阶段）：
  - 阶段 1："你刚来到神塔。让我考考你..."
  - 阶段 2 切场（HP 50%）："不错。但还要看你能否综合..."
- 战后："你通过了字母厅的考验。继续前进。"
- 立绘：4 张（双阶段 × 觉醒）

### 1F Bosses（之前已设计，重申）

#### 迷雾低吟者（1F-A）
- 战前："I... am... very... 啊…我是什么…"
- 战后（被救）："谢谢你…我记起来了，我是 brave 词灵。"

#### 静默叹息者（1F-B）
- 战前："我已经...忘记了...怎么形容自己..."
- 战后："是的...我是 quiet。安静。"

#### 图书管理员（1F-Final）
- 设定：神塔英语层主管，封印自己以保护最后一本书
- 战前（双阶段）：
  - 阶段 1："...你来了…我是这层的守关人…"
  - 阶段 2（HP 50%）："等等！让我让你看一些东西…" [闪回 - 当年塔崩塌图书馆守住最后一本书]
  - 阶段 2 续："接受最后的考验！"
- 战后："谢谢…终于有人能继承了…带上这本书。"
- 战利品：传说装备「沉默之书」+ 蓝图碎片 ×3

### 2F Bosses

#### 家族散乱者（2F-A）
- 设定：本是教家庭称谓的导师
- 战前："这是...mother？还是...father？我分不清了..."
- 战后："母亲 mother，父亲 father。我都记起来了。"

#### 形体迷失者（2F-B）
- 设定：教身体名词的灵体
- 战前："我的...head 在哪里？hand？foot？"
- 战后："谢谢你帮我找回每个部位的名字。"

#### 家庭守护者（2F-Final）
- 设定：守护家庭与代词的灵体
- 战前（双阶段）：
  - 阶段 1："I, you, he, she, it...这些代词混在了一起..."
  - 阶段 2（HP 50%）："让我看看你能不能用对它们..."
- 战后："这块护身符给你，会保护你的家人。"
- 战利品：传说装备「血缘之环」+ 蓝图碎片 ×3

## 楼层叙事节奏

每楼层都是这样的节奏：

```
[楼层简介]（CutscenePlayer 播放 floor_intro_<id>.json）
   导师 NPC 简短介绍单元主题 + 鼓励
   ↓
[备战界面] 编辑卡组 + 复习卡片 + 启程
   ↓
[Run 开始] 路径地图（Slay-Spire 三幕）
   ├─ 节点（战斗 / 商人 / 休息 / 谜题 / 事件）
   ├─ Boss A 战前对白 → 战斗 → 战后对白
   ├─ 中场营地（卡片 3 选 1 + 营地行动）
   ├─ Boss B 战前对白 → 战斗 → 战后对白
   ├─ 中场营地
   ├─ Final Boss 战前对白（多阶段切场）→ 战斗 → 战后对白
   ↓
[楼层通关]（CutscenePlayer 播放 floor_complete_<id>.json）
   导师祝贺 + 暗示下一层
   ↓
[Run 结算] 词晶 + 蓝图碎片 + 装备入仓库
   ↓
[回知识城]
```

## Phase 2 / 3 故事预告

**Phase 2 内容**：
- 3F 一般现在时 + 时间之主
- 4F 一般过去时 + 回忆之主
- 5F 现在进行时 + 此刻之灵
- **关键剧情**：4F 通关后开始出现"前辈守护者"线索，5F 揭示遗忘之主可能曾是同行。

**Phase 3 内容**：
- 6F-9F 各楼层
- 10F 终局：遗忘之主真实身份揭示，玩家面对前辈守护者的灵魂残影
- 通关结局：选择是消灭还是救赎遗忘之主

→ **小学生友好的情感深度**：知识是美好的，失去它的人会被扭曲，救援比毁灭更有力量。
